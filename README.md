## 首次设置

1. 安装后允许通知。
2. 首次从 App 内更新时开启“允许安装此来源”，然后返回 App 继续安装。
3. 如 vivo 延迟后台通知，可在系统设置中允许薄肌记录器后台活动/自启动，具体名称以当前 OriginOS 为准。打开 App 也会检查更新。

版本检查通常每小时安排一次，实际时间受网络和系统省电策略影响，不保证实时推送。下载需要网络能访问 GitHub。正常覆盖安装保留记录，卸载或清除数据会删除记录。
